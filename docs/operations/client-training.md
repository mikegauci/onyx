# Client training checklist (PR-027)

Run through this with each new client's owner and staff before they use Onyx with customers.

**Owner**

- [ ] Accept the invitation link and sign in.
- [ ] Settings → General: name, display name, brand colour, timezone.
- [ ] Settings → Members: invite staff with the right role (members draft; admins approve).
- [ ] Inbox → Channels: check the email address and WhatsApp number are connected.
- [ ] Outbound: draft expiry, reminder and urgent timings.
- [ ] Settings → Audit log: where to see who did what.

**Staff**

- [ ] Find a conversation, link it to a contact, assign it.
- [ ] Draft a reply; see it wait for approval.
- [ ] (Admins) Approve, edit and approve, or reject a reply; send an approved reply.
- [ ] Tasks: open reminders, mark them done.
- [ ] Blocked addresses: what STOP and bounces mean.

**Safety**

- [ ] Nothing reaches a customer without approval (unless the auto-send policy is agreed).
- [ ] What to do if something looks wrong: write down the "Reference" shown with the error
      and tell Onyx support.
- [ ] Never paste customer data into email or chat with support; send the reference.
